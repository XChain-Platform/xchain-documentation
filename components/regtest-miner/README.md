# XChain Platform Regtest Miner

## What is xchain-regtest-miner

xchain-regtest-miner is an auto-mining service for regtest development environments. In regtest mode, Bitcoin-family coin nodes do not mine blocks automatically — developers must mine manually or script it. The regtest miner eliminates this friction by watching the mempool and mining blocks automatically whenever transactions are detected.

This service is for development and testing only. It must not be run against mainnet or testnet nodes.

## How It Works

The miner polls the coin node's mempool every 1 second using `getrawmempool`. When a new unconfirmed transaction appears, the miner starts a countdown timer:

- On detecting the first transaction, a 30-second countdown begins
- Each additional transaction that arrives before the timer expires resets the timer to 5 seconds
- When the timer reaches zero, the miner calls `generatetoaddress` to mine a block containing all pending mempool transactions

This batching strategy groups related transactions — such as a P2SH fund transaction and its corresponding spend — into the same block, which is important for correct platform behavior since some encoding formats require both transactions to be confirmed together.

## JSON-RPC Methods

The miner exposes a JSON-RPC API for test orchestration:

| Method | Description |
|---|---|
| `ping` | Health check; returns `pong` |
| `send_funds` | Send regtest coins to a specified address (for test wallet funding) |
| `fill_mempool` | Broadcast multiple funding transactions to populate the mempool |
| `continue_mining` | Resume auto-mining after a manual pause |
| `set_mining_time` | Adjust the countdown timer duration at runtime |

The `send_funds` method constructs and broadcasts raw PSBTs to fund test addresses without requiring a pre-funded wallet in the caller.

## Wallet Management

The miner maintains an internal wallet with coins generated by early regtest blocks (mined on startup if the chain is empty). It uses this wallet to fulfill `send_funds` requests. PSBT construction is handled internally — the miner does not depend on xchain-encoder for funding operations.

## Configuration

| Parameter | Description |
|---|---|
| `coin` | Chain identifier — `BTC`, `LTC`, or `DOGE` |
| `network` | Must be `regtest` |
| `rpcHost` | Coin node JSON-RPC hostname |
| `rpcPort` | Coin node JSON-RPC port |
| `rpcUser` | Coin node RPC username |
| `rpcPass` | Coin node RPC password |
| `port` | Miner JSON-RPC API port |
| `miningDelay` | Initial countdown timer in milliseconds (default: 30000) |
| `resetDelay` | Timer reset duration on new transaction (default: 5000) |

## Installation

```bash
git clone https://github.com/XChain-platform/xchain-regtest-miner.git
cd xchain-regtest-miner
npm install
npm run api
```
