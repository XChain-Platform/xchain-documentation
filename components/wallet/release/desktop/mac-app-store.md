# Desktop: Mac App Store

Mac App Store distribution is planned but not yet available. It requires enrollment in Apple's developer program and store-specific signing credentials that are still pending.

Until it ships, macOS users should install the direct-download build described in [macOS](macos.md), which is available today and covered by the standard [release-verification recipe](../verify-release.md).

This page will be filled in once the Mac App Store lane is live.
