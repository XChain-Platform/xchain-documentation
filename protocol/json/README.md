# JSON Schemas

Machine-readable JSON artifacts for the XChain protocol.

## Token Information Standard (v1.0.0)

The off-chain token metadata document referenced by a token's on-chain `DESCRIPTION` URI.

- [Schema](./token-information-standard-v1.0.0-schema.json) — JSON Schema for the metadata document.
- [Example](./token-information-standard-v1.0.0-example.json) — a worked example that conforms to the schema.

See the [Token Information Standard](../Token_Information_Standard.html) for the field-by-field reference.
